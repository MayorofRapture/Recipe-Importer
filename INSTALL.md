# Installation

The previous version of this file contained Codex skill-copy and commit
instructions. Those were one-time repository-maintenance instructions and are
superseded; they are not user installation steps.

For current Windows PowerShell setup, API configuration, optional local OCR,
and local review-app startup, follow the **First-time setup** section in
[README.md](README.md). Use `requirements-lock.txt` to recreate the verified
Python 3.14 environment. Keep `.env`, source scans, and the `output/` library
local and out of version control.

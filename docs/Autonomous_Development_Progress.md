## Limits

- Live Gemini and Mealie behavior remains unverified. Fixture tests do not establish provider compatibility, shared-account quota behavior, or real server response semantics.
- Keyboard-only completion, a full accessibility tree, all contrast pairs, all non-text contrast pairs, and screen-reader behavior were not verified. See the criterion-by-criterion browser audit.
- Earlier R1-R6 browser tests used synthetic inputs only. P0 additionally used an isolated copy of the local library and read-only original source paths; private contents, credentials, scans, and output history were excluded from committed evidence. The existing user browser sessions were not remotely inspectable, so their loaded version remains unverified; isolated browser runs used the current checkout and its virtual environment.
